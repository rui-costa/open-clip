# ADR-004: Centralized Dataclass Pattern

## Requirement
All project entities must share a unified data schema to prevent configuration drift and circular dependencies as the system scales.

## Decision
1. **Centralized Definition**: All project-related data structures (Highlight, Clip, ProjectFileSettings, etc.) must be defined in `backend/src/dataclasses/data.py`.
2. **Schema Uniformity**: All services and models must import their data schemas exclusively from this centralized module.
3. **Pure Structure**: Dataclasses in this module shall strictly define structure and contain no business logic or persistence methods.

## Justification
* **Single Source of Truth**: Centralizing schemas eliminates configuration drift and ensures all system components operate on the same data contracts.
* **Dependency Cleanliness**: Removing scattered dataclass definitions eliminates common circular dependency patterns, improving architectural stability.
